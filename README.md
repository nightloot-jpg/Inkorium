# Inkorium

Welcome to the **Inkorium** project.

This is a fresh TanStack Start boilerplate configured with:
- React 19
- TypeScript
- Vite
- Tailwind CSS v4
- Docker production setup

## Development

```bash
npm install
npm run dev # start development server
```

## Production

```bash
npm run build
npm start # run production server
```

## Docker

```bash
docker-compose up --build -d
```
